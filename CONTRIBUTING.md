# Contributing

Contributions are welcome through pull requests.

1. Create a Python 3.11–3.13 virtual environment.
2. Install the development dependencies with `python -m pip install -e ".[dev]"`.
3. Run `make lint` and `make test` before opening a pull request.
4. Keep changes focused and include tests for new behavior.

Please do not commit generated models, MLflow runs, prediction logs, credentials, or local environment files.
